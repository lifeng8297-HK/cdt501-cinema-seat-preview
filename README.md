# 映前 · 影院选座与视角预览

计算机系统课程的独立演示。选座后可以预览三维观影视角、在前后排之间切换，或查看俯视和台阶剖面。确认座位是本地模拟。

使用浏览器打开 `index.html` 即可运行。三维预览使用 WebGL，俯视与剖面图使用 Canvas。

## 数据和画面

- 东莞华南 MALL、北京石景山和香港 iSQUARE 用作几何案例。公开银幕尺寸的出处可在网页的「资料来源与估算」里查看。
- 座位网格、台阶标高、幕下沿高度、字幕位置及相对声场属于示意模型。声场可在分析页打开。
- 影厅画面、示例影片画面和字幕由本项目代码生成。影院名称用于标识案例，网页为独立课程演示。
